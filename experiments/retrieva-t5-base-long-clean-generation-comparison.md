# retrieva-jp/t5-base-long 追加改善実験

実行日: 2026-06-07

## 目的

前回の `retrieva-jp/t5-base-long` LoRA 実験では、`google/mt5-small` よりは改善したものの、「総理」「でございます」「であります」の反復が強く、要約文としてはまだ不安定だった。

今回は次の 2 点で追加改善を試した。

- 生成時の反復抑制を強める
- 入力文字起こしから明らかなノイズを除去し、Proposed のラベル形式を短くする

## 追加した処理

`data/prog/prepare_summarization_data.py` に、次のオプションを追加した。

```bash
python data/prog/prepare_summarization_data.py \
  --output-dir data/summarization_compact_clean \
  --proposed-format compact \
  --clean-source
```

`--clean-source` では、文字起こし中の定型ノイズと短い反復句を削る。

`--proposed-format compact` では、Proposed 入力を次のように短くする。

```text
委員長 <question> <neutral> 玉木雄一郎さん。
```

従来形式:

```text
[委員長] act: question | stance: neutral | text: 玉木雄一郎さん。
```

## 実行条件

強めた生成設定:

- `no_repeat_ngram_size=5`
- `repetition_penalty=1.5`
- `length_penalty=0.8`
- `num_beams=4`
- `generation_max_length=256`

compact/clean データでの Baseline:

```bash
python data/prog/finetune_mt5_summarizer.py \
  --condition baseline \
  --tuning-mode lora \
  --dataset-dir data/summarization_compact_clean \
  --model-id retrieva-jp/t5-base-long \
  --output-root runs/retrieva-t5-base-long-compact-clean \
  --local-files-only \
  --learning-rate 1e-3 \
  --no-repeat-ngram-size 5 \
  --repetition-penalty 1.5 \
  --length-penalty 0.8
```

compact/clean データでの Proposed:

```bash
python data/prog/finetune_mt5_summarizer.py \
  --condition proposed \
  --tuning-mode lora \
  --dataset-dir data/summarization_compact_clean \
  --model-id retrieva-jp/t5-base-long \
  --output-root runs/retrieva-t5-base-long-compact-clean \
  --local-files-only \
  --learning-rate 1e-3 \
  --no-repeat-ngram-size 5 \
  --repetition-penalty 1.5 \
  --length-penalty 0.8
```

## 数値結果

| 条件 | データ | 生成設定 | test loss | char ROUGE-L |
| --- | --- | --- | ---: | ---: |
| retrieva LoRA Baseline | 通常 | 前回設定 | 5.3284 | 0.1412 |
| retrieva LoRA Proposed | 通常 | 前回設定 | 5.3585 | 0.1334 |
| retrieva LoRA Baseline | 通常 | 反復抑制強化 | 5.3284 | 0.1524 |
| retrieva LoRA Proposed | 通常 | 反復抑制強化 | 5.3585 | 0.1443 |
| retrieva LoRA Baseline | compact/clean | 反復抑制強化 | 5.3186 | 0.1664 |
| retrieva LoRA Proposed | compact/clean | 反復抑制強化 | 5.1624 | 0.1374 |

最良は `retrieva-jp/t5-base-long` + LoRA + Baseline + compact/clean + 反復抑制強化で、char ROUGE-L は `0.1664` だった。

前回の最良値 `0.1412` から見ると、絶対値で `+0.0252`、相対で約 `+17.9%` 改善した。


### test_002: 山添拓議員と小泉防衛相、非核三原則

参照要約:

```text
参議院外交防衛委員会が20日に開かれ、共産党の山添拓議員が、小泉進次郎防衛相の国会答弁姿勢についてただした。山添氏は、防衛力変革推進本部会議の初会合で小泉防衛相が「あらゆる選択肢を排除せず、これまでにないスピード感で積極果敢に議論、そして決断」と述べた点を挙げ、「大臣の発言には憲法九条も専守防衛も必要最小限度もなく、実力組織を預かる者の言葉として違和感しかない」と批判した。 小泉氏は、「日本の平和と独立、主権、領土・領海・領空、隊員と家族の命を守り抜くために必要な要素について、あらゆる選択肢を排除せずに検討するのは当然だ」と応じた。 さらに山添氏は、非核三原則をめぐり「単なる政策上の方針ではなく、国会の全会一致決議で表明されてきた国是だ」と指摘し、見直しの可能性をただした。茂木敏充外務大臣は「政府としては非核三原則を政策上の方針として堅持しており、見直しの検討が進んでいるとは承知していない」と述べるに留めた。
```

Baseline compact/clean:

```text
要約: 山添拓君 山添拓です 山添拓でございます 山添拓議員に伺います 大臣の答弁についてお聞きしたいと思います 山添拓さん はを申し上げますではありますけれどもしたということはのしましたの答弁がありましたのとしております がとして説明したことはないと思いますしているんですかしますの発言がありますの質問がありましたが避けてきたとこう述べていますよそのようにが避けてきたと
```

Proposed compact/clean:

```text
の答弁であります。 山添拓君 大臣に伺います 総理はの発言が明らかになったということを認識をいたしております 山添拓議員が質問をされましたが、政府の立場は一貫した政府の方針を貫くと答弁をいたしました。 また、今年5月22日党委員会において高市総理の答弁についてお聞きしたいと思うんですか 閣議の答弁でございまして安倍総理の答弁については次のとおりですらなの へではありませんでした からを
```

- 両者とも文法はまだ崩れており、ニュース要約としては不十分。

### test_003: 現金給付報道、減税、党首討論

参照要約:

```text
石破茂首相（自民党総裁）と野党党首による党首討論が11日夕、国会で行われた。国民民主党の玉木雄一郎代表は、税収の上振れ分を原資に「選挙前に3万〜4万円を現金給付する」との報道を取り上げ、「バラマキではなく減税こそが筋だ」と訴えた。「税収は自民党や公明党のものではなく、国民のものだ」と述べ、納税者に対して減税で返すべきとの考えを示した。 石破茂首相は「そのような報道は承知しているが、政府内で検討した事実はない」と明確に否定。さらに「税収を自民党・与党のものと考えたことは一度もない。そのような侮辱はやめていただきたい」と反論した。続けて「困っている方への支援に力を入れる」とし、「一生懸命額に汗して働いた人の所得が増えるように取り組んできた」と強調。「物価高にどう対応するか、政府として強い認識を持っている」と述べた上で、「国民に向けてバラ撒くというつもりはない」と強調した。
```

Baseline compact/clean:

```text
国民民主党代表玉木雄一郎です。総理、挙手をお願いします。玉木雄一郎さん。総理。総理。総理はどうですか。総理。総理の答弁がぶれています。玉木さん。総理に伺いました。総理はどうでしょうか。総理。総理、お願いします。総理。。総理。総理。総理。総理。総理。総理するんですか。総理。総理。総理。総理大臣。総理。総理してください。総理。総理ね総理。総理総理で振
```

Proposed compact/clean:

```text
の財政状況には全く変わりはございません。 委員長 <concern> <neutral> 玉木雄一郎さん。 委員長 <question> <negative> 質問がぶれていますね。 委員長 要約: 委員長 お願いします。 委員長 よろしくお願いします。 委員長 ありがとうございます。 委員長 ありがとうございました。 委員長 はい。 総理。 するしております自民党としてであります。 委員長 それではどうですか。 委員長 そう思いますか。 委員長
```

変化:

- Baseline は「国民民主党」「玉木雄一郎」は出ているが、「税収」「減税」「現金給付」が出ず、総理反復に崩れている。
- Proposed は compact タグ `<concern> <neutral>` が出力側に漏れており、提案手法としてはまだ改善が必要。
- この例では、通常データ + 反復抑制強化の Proposed の方が `char_rouge_l=0.1696` で局所的には良かった。

## 結論

もう少し上げることはできた。現時点の最良条件は次である。

- モデル: `retrieva-jp/t5-base-long`
- 学習: LoRA
- 入力条件: Baseline
- データ: compact/clean
- 生成: `no_repeat_ngram_size=5`, `repetition_penalty=1.5`, `length_penalty=0.8`
- test char ROUGE-L: `0.1664`

ただし、Proposed は今回の compact ラベル化では伸びなかった。ラベル情報そのものが悪いというより、データ数が少ない状態でタグを入れると、モデルがタグや話者名を出力側へコピーしやすいことが原因と考えられる。

次の改善では、発話ラベルをそのまま入力に混ぜるより、発話ラベルを使って重要発話を抽出し、要約モデルには整理済み本文だけを渡す方が有望である。
